# Ярлыки разбора (triage)

Скиллы говорят о пяти канонических ролях. Здесь эти роли сопоставлены с настоящими строками ярлыков в трекере этого репозитория.

| Ярлык в mattpocock/skills | Ярлык в нашем трекере | Что значит                                       |
| ------------------------- | --------------------- | ------------------------------------------------ |
| `needs-triage`            | `needs-triage`        | Задачу нужно разобрать — решить, что с ней делать |
| `needs-info`              | `needs-info`          | Ждём уточнений от автора задачи                  |
| `ready-for-agent`         | `ready-for-agent`     | Описана полностью, агент может брать без человека |
| `ready-for-human`         | `ready-for-human`     | Нужен человек                                    |
| `wontfix`                 | `wontfix`             | Делать не будем                                  |

Когда скилл упоминает роль («поставь ярлык готовности для агента»), брать строку из правой колонки.

Взяты канонические названия: они однозначны и не пересекаются с уже существующими 32 ярлыками репозитория — те про область (`backend`, `frontend`), технологию (`tech: docker`) и приоритет (`P0`, `P1`, `P2`), а не про стадию разбора. Из пяти в репозитории уже есть только `wontfix`; остальные четыре создаются один раз:

```
gh label create needs-triage    --description "Задачу нужно разобрать" --color FBCA04
gh label create needs-info      --description "Ждём уточнений от автора" --color D876E3
gh label create ready-for-agent --description "Описана полностью, можно отдавать агенту" --color 0E8A16
gh label create ready-for-human --description "Нужен человек" --color 1D76DB
```

Если решите перейти на свой словарь — правьте только правую колонку, скиллы читают её.
